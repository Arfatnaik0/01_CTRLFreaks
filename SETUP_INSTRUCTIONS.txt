================================================================================

Before starting, ensure your computer has the following installed:

1. NODE.JS (Required)
   - Version: 16.0.0 or higher (recommended: 18.x or 20.x)
   - Download from: https://nodejs.org/
   - Verify installation: node --version && npm --version

2. DOCKER & DOCKER COMPOSE (Required)
   - Docker Desktop (includes Docker Compose)
   - Download from: https://www.docker.com/products/docker-desktop/
   - Verify installation: docker --version && docker-compose --version

3. GIT (Required)
   - Download from: https://git-scm.com/downloads
   - Verify installation: git --version

4. CODE EDITOR (Recommended)
   - Visual Studio Code: https://code.visualstudio.com/

================================================================================
                              INSTALLATION STEPS
================================================================================

STEP 1: CLONE THE REPOSITORY
----------------------------
git clone https://github.com/Arfatnaik0/01_CTRLFreaks.git
cd 01_CTRLFreaks

STEP 2: BACKEND SETUP
---------------------
# Navigate to backend directory
cd backend

# Start backend services with Docker
docker-compose up -d

# Verify backend is running (should return JSON data)
curl http://localhost:5000/api/devices

# Alternative verification - check Docker containers
docker-compose ps

STEP 3: FRONTEND SETUP
----------------------
# Navigate to frontend directory (from project root)
cd ../frontend

# Install all Node.js dependencies
npm install

# Start the development server
npm run dev

# The application will be available at: http://localhost:5173

================================================================================
                              TROUBLESHOOTING
================================================================================

COMMON ISSUES AND SOLUTIONS:

1. BACKEND API CALLS FAILING:
   Problem: Frontend can't connect to backend
   Solutions:
   - Check Docker containers: docker-compose ps
   - Restart backend: docker-compose restart
   - View logs: docker-compose logs
   - Verify port 5000 is not occupied

2. FRONTEND WON'T START:
   Problem: npm run dev fails
   Solutions:
   - Clear node_modules: rm -rf node_modules && npm install
   - Check Node.js version: node --version (need 16+)
   - Try different port: npm run dev -- --port 3000

3. DEPENDENCIES WON'T INSTALL:
   Problem: npm install fails
   Solutions:
   - Clear npm cache: npm cache clean --force
   - Delete package-lock.json and try again
   - Use npm install --legacy-peer-deps

4. CHARTS NOT DISPLAYING:
   Problem: Visualizations not showing
   Solutions:
   - Check browser console for Chart.js errors
   - Verify Chart.js dependencies installed correctly
   - Clear browser cache and reload

5. DOCKER ISSUES:
   Problem: Docker containers won't start
   Solutions:
   - Ensure Docker Desktop is running
   - Check available disk space
   - Try: docker system prune (WARNING: removes unused containers)
